# Manuscript Order — The Single Source of Truth for Sequence

**This file is the only place reading order lives.** No chapter file, bible entry, or note carries a number anymore — a title is a stable identifier that never changes, but its *position* is only ever recorded here, as this list's own top-to-bottom order.

**To insert a new scene or chapter:** add one line to this list, wherever it belongs. Nothing else needs to change — no renaming, no renumbering, no touching any other file. Every cross-reference elsewhere in the bible points to a title (e.g. "the Ring chapter"), which stays valid regardless of what gets inserted around it.

**Every agent that needs to know what comes before or after a given chapter — the Writer resolving its Window Rule neighbors, the Continuity Checker doing its full sequential read, Synthesis rebuilding its POV table — reads this file first, in order, top to bottom. Never infer order from filenames or from any number written elsewhere.**

A title with a filename below is written (`chapters/<file>`). A title with no filename is outline-only, in `bible/unit-plans.md`, not yet drafted.
